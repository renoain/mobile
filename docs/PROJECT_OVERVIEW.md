# Kost Care Project Overview

## Deskripsi Aplikasi

Kost Care adalah aplikasi mobile marketplace yang menyediakan jasa kebersihan, penataan, dan pindahan khusus untuk anak kos. Aplikasi ini menghubungkan mahasiswa yang butuh bantuan dengan penyedia jasa terpercaya.

## Target User

- Mahasiswa anak kos usia 18-25 tahun
- Tinggal di kos atau kontrakan
- Sibuk dengan kuliah dan aktivitas
- Ingin kos bersih dan rapi tanpa harus capek sendiri

## Masalah yang Diselesaikan

1. Mau kos bersih sebelum pulang kampung tapi tidak sempat
2. Capek dan mager bersih-bersih setelah liburan
3. Pindahan kos merepotkan (packing, angkut, pindah)
4. Layanan existing masih manual via TikTok dan WhatsApp

## Solusi

Aplikasi mobile dengan fitur:

1. Pesan jasa cleaning (basic dan deep cleaning)
2. Pesan jasa penataan kos (lemari, barang, pakaian)
3. Pesan jasa packing dan pindahan kos
4. Booking cepat, harga transparan, tracking status

## Fitur Utama

### MVP

- Auth (login, register)
- Katalog layanan
- Form pemesanan
- Pembayaran manual
- Riwayat pesanan
- Profil user

### Fase 2

- Chat in-app
- Rating dan review
- Notifikasi push
- Payment gateway

### Fase 3

- Promo dan voucher
- Referral
- Cleaner app terpisah
- Wallet cleaner

## Model Bisnis

- Komisi per order (10-20 persen)
- Biaya layanan (platform fee)
- Potensi langganan untuk user rutin

## Kompetitor

- Layanan manual via TikTok dan WhatsApp
- Aplikasi cleaning umum (belum fokus anak kos)
- Jasa freelance individual

## Unique Value Proposition

- Fokus khusus anak kos
- Booking cepat dan terstruktur
- Harga transparan
- Layanan lengkap (cleaning, penataan, pindahan)
- Tracking status real-time

## Tech Stack

- Mobile: Flutter
- State Management: Riverpod (nanti)
- Navigation: go_router (nanti)
- Backend: Supabase (nanti)
- HTTP: Dio (nanti)
